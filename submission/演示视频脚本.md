# 《骑伴 AI 智能电动车中控屏》演示视频脚本

目标时长：4 分 30 秒；最长不得超过 5 分钟。

## 0:00-0:20 开场

画面：开发板、2.8 寸屏和作品名称同框。

旁白：骑伴 AI 是基于 Gemini-S1 和 openvela 的智能电动车中控屏，将仪表、离线导航、语音入口和主动安全提醒集中到车载端。

## 0:20-1:00 系统启动与仪表

画面：上电启动，展示速度、电量、续航、里程、骑行时长。

操作：在串口执行：

```bash
qiban_vehicle_service serve
qiban_sensor_bridge write speed_kmh 26
qiban_sensor_bridge write battery_percent 18
```

要点：展示状态更新、超速和低电量提醒。若 Agent 未启用，只演示 UI 现有告警，不宣称 Skill 闭环完成。

## 1:00-2:10 离线地图与导航

画面：切换地图页，缩放、平移、显示当前位置，长按选择终点。

操作：

```bash
qiban_sensor_bridge location 112.938814 28.228209
qiban_nav_service start 任意目的地 112.950000 28.220000
```

要点：说明离线瓦片和 `road_graph.bin` 在断网时仍可使用；若路线数据区域不匹配，只展示地图，不宣称规划成功。

## 2:10-3:00 语音和多媒体

画面：切换语音页，输入“导航到软件园二期”；展示音乐页播放/暂停。

操作：

```bash
qiban_voice_service intent 导航到软件园二期
qiban_music_service status
```

要点：当前以文本意图和录放音工具为主；没有跑通 ASR/TTS 时，不展示为完整语音识别。

## 3:00-3:40 模块与 openvela 能力

画面：快速扫过串口状态和代码结构。

旁白：图形使用 LVGL、LCD 和触控；多媒体使用 openvela 音频设备与播放器；车辆、导航、地图、天气和多媒体通过 `/data/qiban_*.json` 解耦。

## 3:40-4:15 AI 能力

画面：展示 `qiban_ai skill list`；如当前固件没有该命令，改为展示源码中的 Skill 列表。

旁白：项目实现了超速、低电量、疲劳、导航转向和急刹等 10 个规则 Skill。当前提交版本的 Agent 尚未进入默认固件，属于已完成源码但未完成真机验收的部分。

## 4:15-4:30 收尾

画面：回到仪表首页，作品与硬件同框。

旁白：骑伴 AI 验证了 openvela 在两轮出行中控上的图形、导航、多媒体和主动服务能力。

## 导出要求

- 分辨率建议 1080p，横屏 16:9。
- 使用 MP4/H.264，文件名建议 `骑伴AI-演示视频.mp4`。
- 保留关键操作原声或字幕，不加入无法复现的效果镜头。
- 最终检查总时长不超过 5 分钟。
